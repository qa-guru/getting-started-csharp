# Getting started with C# UI tests

Three ways to do the same UI test: open GitHub search, search for `qa.guru`, assert results contain `QA.GURU`.

- `SeleniumSearchTests.cs` — Selenium WebDriver
- `PuppeteerSharpSearchTests.cs` — PuppeteerSharp (auto-downloads browser)
- `PlaywrightSearchTests.cs` — Playwright (auto-installs browser)

## Run

```bash
dotnet test
```
